How It Works

Vault was built to solve a massive pain point: developers bloating their Postgres databases with bytea columns or struggling with complex AWS IAM permissions.

Vault stores object metadata, versions, and SHA-256 checksums in your PostgreSQL database so you can run SQL JOINs against application tables while streaming binaries safely to local disks with pre-verified reads.

# Stream raw binary payload via Vault REST (with X-API-Key)
curl -X PUT -L "http://localhost:8081/api/v1/objects?key=users/avatar.jpg" \
  -H "X-API-Key: $VAULT_API_KEY" -H "Content-Type: application/octet-stream" \
  --data-binary @avatar.jpg

{"objectId":"users/avatar.jpg","checksum":"...","size":...}

Get Started in 60 Seconds

1. Clone & Spin Up

Deploy a 3-node local cluster instantly with Docker Compose.

docker-compose up -d --build

2. Verify Cluster

Check the custom health indicators to ensure quorum is met.

curl localhost:8081/actuator/health

3. Monitor

Open Grafana on port 3000 to view realtime metrics (reads, writes, repairs).
