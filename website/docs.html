Quickstart Guide

Vault is a highly available distributed storage engine. It runs best in a containerized environment. This guide shows how to spin up a local 3-node cluster.

1. Prerequisites

You must have Docker and Docker Compose installed on your system.

2. Launch the Cluster

Navigate to the project root directory and run:

docker-compose up -d --build

This spins up:

  • 3 Vault Nodes (Ports: 8081, 8082, 8083)
  • 1 PostgreSQL instance (Port: 5432)
  • Prometheus & Grafana (Port: 3000)

3. Verify Cluster Health

Check the custom health endpoint to ensure the cluster has elected a leader and established quorum:

curl -s http://localhost:8081/actuator/health

You should see "status": "UP" along with cluster topology details.

S3-Compatible API Reference (Experimental)

Vault includes an experimental S3-style path adapter for testing alongside standard native REST endpoints. AWS SigV4 is not implemented; clients must supply X-API-Key.

Upload an Object

PUT /s3/{bucket}/{key}

Accepts raw binary payloads up to 128 MiB (multipart forms return HTTP 415) and replicates via cluster quorum.

curl -X PUT http://localhost:8081/s3/my-bucket/folder/image.png \ -H "X-API-Key: $VAULT_API_KEY" \ -H "Content-Type: application/octet-stream" \ --data-binary @local-image.png

Note: All /api/* and /s3/* routes enforce X-API-Key authentication configured via VAULT_API_KEYS.

Download an Object

GET /s3/{bucket}/{key}

Streams the verified object from storage.

curl -H "X-API-Key: $VAULT_API_KEY" \ http://localhost:8081/s3/my-bucket/folder/image.png -o downloaded-image.png

Delete an Object

DELETE /s3/{bucket}/{key}

Creates a tombstone version marked for asynchronous garbage collection.

curl -X DELETE -H "X-API-Key: $VAULT_API_KEY" \ http://localhost:8081/s3/my-bucket/folder/image.png

Postgres-Native Architecture

Vault is engineered for apps that already use PostgreSQL.


  • Relational Integrity: File metadata lives in the objects and replicas tables in your database. You can join your app tables with Vault's tables cleanly.
  • Bounded Streaming: Files stream to local disk via collision-free SHA-256(key) object locators in bounded 8 KB chunks without buffering entire payloads in heap.
  • PostgreSQL-Coordinated Leader Lease: Nodes use Postgres election_state leases and monotonic terms for leader coordination.
  • Self-Healing: Background scrubbers verify SHA-256 checksums against metadata and trigger repair from peer replicas.
