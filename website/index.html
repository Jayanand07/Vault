How It Works

Vault was built to solve a massive pain point: developers bloating their Postgres databases with bytea columns or struggling with complex AWS IAM permissions.

With Vault, you get the best of both worlds. It acts exactly like Amazon S3 (compatible with standard SDKs), but it stores the metadata in your PostgreSQL database. Now you can run SQL `JOIN`s between your users and their files, while the heavy binaries stream directly to local high-speed NVMe drives.

# Works seamlessly with existing S3 clients and AWS SDKs
aws --endpoint-url http://vault-cluster:8081/s3 \
  s3 cp avatar.jpg s3://users/avatar.jpg

upload: avatar.jpg to s3://users/avatar.jpg

Get Started in 60 Seconds

1. Clone & Spin Up

Deploy a 3-node local cluster instantly with Docker Compose.

docker-compose up -d --build

2. Verify Cluster

Check the custom health indicators to ensure quorum is met.

curl localhost:8081/actuator/health

3. Monitor

Open Grafana on port 3000 to view realtime metrics (reads, writes, repairs).

Open Grafana
