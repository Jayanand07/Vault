Bit-Rot & Read-Repair Simulation

Vault continuously guarantees data integrity. See what happens when a disk experiences silent byte corruption.

1. How Bit-Rot is Detected

Every object uploaded has its cryptographic SHA-256 stored in PostgreSQL. Before serving any read, a node verifies the full local FileChannel SHA-256 and expected size before returning HTTP 200—corrupt bytes are never sent.

2. Peer Fallback & Stage-Verify Repair

If the local copy is missing or fails pre-verification, the node transparently streams a copy from a healthy peer into a staged temp file, verifies SHA-256 before serving HTTP 200, and installs the verified repair asynchronously.
